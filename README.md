# South-View · A Living Archive

A buildless, responsive demo of the supplied white paper. Open `dist/index.html` directly, or serve `dist` with a static HTTP server. No dependency installation is required.

The demo includes three event paths, five profiles selected from South-View's History in the Neighborhood page, searchable and filtered stories, browser-local bookmarks, linked sources, and a downloadable community memory draft. Contributions are not sent anywhere.

Historical connections are explicit: the 1906 stories have documented event-specific links; Juneteenth uses emancipation and Reconstruction contexts; the Child Murders path uses clearly labeled thematic community connections. Direct participation is not asserted for those contextual links. Victims' stories require further family-informed research.

Portraits and biographical source links are credited within each story and in Sources & editorial notes. This is a private student concept demonstration, not an official foundation publication.

Preview: `python -m http.server 4173 --bind 127.0.0.1 --directory dist`
